## 0. Design Read (формат tasteskill) и режимы

> **Reading this as:** electronic-artist press kit for booking agents and promoters, with a cinematic dark-club language lit by one warm sunrise light (red to orange), leaning toward a custom token system on Next.js + Tailwind v4 + shadcn-registry components from 21st.dev + GSAP/Motion scroll choreography + full-bleed video.

- **Режим impeccable:** `Experience` (визитор внутри мира артиста, интерфейс отступает) + `Persuade` в блоке Contact.
- **Dials tasteskill:** `DESIGN_VARIANCE: 8` · `MOTION_INTENSITY: 8` · `VISUAL_DENSITY: 3`.
- **high-end-visual-design:** применять при выборе каждого визуального хода (материалы, свет, глубина, кинематографичность).
- **Доноры из awesome-design-md** (`docs/design-refs/`): **Ferrari** (один гоночный красный на почти черном, красный используется скупо, крупные числа как «спецификации», строки календаря гонок → наш тур) и **Runway** (видео и фото = интерфейс, сам интерфейс почти невидим, кинематографичные кадры на весь экран). Брать принципы, не копировать бренд.

## 2. Концепция и настроение

**«Ночь, которая заканчивается рассветом».** Страница — клубная ночь. Черная сцена, свет сцены, люди. Единственный теплый источник света — солнце SUNRISE: оно встает на первом экране (портрет на красно-оранжевом фоне — это и есть рассвет), его лучи проходят через всю страницу и в финале у контактов солнце садится за горизонт.

Три слова: **теплый свет в темноте · кинематографично · уверенно.**
Антонимы: кислотный рейв-флаер, корпоративная презентация, шаблонный dark-SaaS.

## 3. Палитра

Принцип (Ferrari + tasteskill Color Lock): **почти черный холст, белый текст и один теплый источник света.** Теплый свет существует в двух формах: сплошной фирменный красный (UI-акцент) и градиент «рассвет» (только как свет/поверхность, не как текст). Синий, зеленый, фиолетовый появляются только внутри видео.

### 3.1 Токены

| Токен | HEX | Роль |
|---|---|---|
| `--ink-950` | `#0A0909` | фон страницы (не чистый `#000`) |
| `--ink-900` | `#121011` | навбар, поднятые поверхности |
| `--ink-800` | `#1B1819` | карточки, ячейки бенто |
| `--ink-700` | `#2B2527` | линии 1px, обводки |
| `--ink-500` | `#5E5457` | disabled |
| `--fog-400` | `#A1979A` | вторичный текст (7.0:1 на ink-950) |
| `--bone-100` | `#F2EFEE` | основной текст (17.4:1) |
| `--white` | `#FFFFFF` | логотип, гигантские цифры, текст на градиенте |
| `--sun-500` | `#D82E2F` | **фирменный красный** (с логотипа): CTA, плашки, лучи, активные состояния |
| `--sun-400` | `#EE4542` | hover красного, свечение LED-цифр |
| `--sun-700` | `#8F1719` | тени и глубина на красном |
| `--dawn-900` | `#810104` | левый/нижний край градиента рассвета (с фото) |
| `--dawn-600` | `#DD2C05` | середина градиента (с фото) |
| `--dawn-400` | `#FE6C04` | правый/верхний край градиента (с фото), hover CTA |
| `--paper-100` | `#F2EFEE` | светлая поверхность (одна светлая карточка или заглушка галереи) |

Контраст проверен: белый на `--sun-500` 4.83:1, белый на `--dawn-600` ≥ 4.5:1 для текста от 18px bold; `--sun-500` на `--ink-950` 4.12:1, поэтому красный текст только от 24px или bold от 19px.

### 3.2 Градиенты (только свет)
- `--g-dawn` (поверхность hero, CTA-баннеры, заглушки): `linear-gradient(100deg, #810104 0%, #B50406 22%, #DD2C05 50%, #F55005 76%, #FE6C04 100%)` — снято с фона портрета, совпадает с ним без шва.
- `--g-sunrise` (восход у горизонта): `radial-gradient(60% 45% at 50% 100%, #FE6C04 0%, #DD2C05 22%, #8F1719 48%, #3A0A0B 72%, #0A0909 100%)`.
- `--g-curtain` (REF-2): `repeating-linear-gradient(90deg, rgba(10,9,9,.55) 0 2px, transparent 2px 22px)` поверх `--g-sunrise`. Только как изображение света сцены.
- `--g-vignette`: `radial-gradient(120% 90% at 50% 40%, transparent 55%, rgba(10,9,9,.92) 100%)` — поверх каждого видео.

### 3.3 Правила
- Теплый свет занимает **≤ 10 % площади** экрана, кроме трех моментов: hero (портрет), баннер-CTA перед контактами, финальный «закат».
- Градиент никогда не идет в текст (запрет gradient text).
- Плашка-выделение одного слова: белый текст на `--sun-500`, r=999, поля `0.04em 0.32em`. Не больше одной на экран.
- Светлой темы нет (сцена ночная). Исключение — светлые заглушки галереи (см. §10).

## 4. Типографика

### 4.1 Гарнитуры (self-host WOFF2 через `next/font/local`, `display: swap`, Latin + Latin-Ext)

| Роль | Шрифт | Лицензия | Почему |
|---|---|---|---|
| **Display** | **Outfit** (variable 100–900; используем 200, 500, 600, 700) | OFL (Google Fonts) | геометрия как у вордмарка SUNRISE и у REF-3/REF-4; легкие начертания для гигантского имени (REF-4), жирные для заголовков |
| **Text / UI** | **General Sans** (400, 500, 600) | Fontshare, бесплатно для коммерции | гротеск с характером, не Inter |
| **Data** | **JetBrains Mono** (500), `tabular-nums` | OFL | только реальные данные: даты тура, телефоны, ранги |

Запрещено: Inter, Fraunces, Instrument Serif, любые засечки, системные Impact/Arial Black, смешение гарнитур внутри одного заголовка.

### 4.2 Шкала

|---|---|---|---|---|---|
| `--t-name` | `clamp(6rem, 24vw, 26rem)` | Outfit 600 | -0.04em | 0.8 | **только** слово SUNRISE в hero (REF-4), обрезается краем |
| `--t-giant` | `clamp(6rem, 20vw, 20rem)` | Outfit 200 / 600 | -0.04em | 0.82 | графические числа: 90 / 7 / 43 / 120 / 35,000 / 20,000 |
| `--t-display` | `clamp(2.75rem, 6.8vw, 6rem)` | Outfit 600 | -0.03em | 0.95 | заголовки секций (max 6rem, impeccable) |

### 4.3 Правила набора
- PromoKit набран капсом целиком. На сайте заголовки в **lower/sentence case**, капс только в `--t-meta`/`--t-micro` и в названиях клубов.
- Фирменный `//` — часть заголовка: `// progress`, `// contact`, `bangkok // pattaya`. `//` красный, текст белый.
- Микротипографика всегда привязана к крупному объекту, никогда не висит в углу сама.
- `text-wrap: balance` для заголовков, `pretty` для абзацев.
- `tabular-nums` во всех датах и счетчиках.
- В видимом тексте только дефис `-`. Никаких em-dash и en-dash (tasteskill §9.G).

## 5. Сетка

| Брейкпоинт | Ширина | Колонки | Гаттер | Поля |
|---|---|---|---|---|
| `xs` | < 640 | 4 | 16 | 16 |
| `sm` | 640–1023 | 8 | 20 | 32 |
| `md` | 1024–1439 | 12 | 24 | 48 |
| `lg` | 1440–1919 | 12 | 24 | 64 |
| `xl` | ≥ 1920 | 12 | 32 | контейнер 1792 по центру |

- `--page-x: clamp(16px, 4.2vw, 64px)`.
- Ширины блоков: **full-bleed** (видео, свет), **inset** (контейнер с отступом `--page-x` и скруглением, как hero REF-3), **wide** (12 колонок), **narrow** (колонки 3–10).
- Анти-центр (VARIANCE 8): центрированная композиция разрешена только для солнца (hero-восход, закат) и веера-дуги. Остальное — асимметрия.
- Гигантские слова и числа могут вылезать за край и обрезаться (REF-4). Обычный текст — никогда.

## 6. Пространство и ритм

### 6.1 Шкала отступов (база 4, совпадает с лестницей Ferrari)
`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128 · 192 · 256`
- Внутри группы: 8–16. Между группами: 48–96.
- Между секциями: `--section-y: clamp(96px, 16vh, 192px)`; у full-bleed видео 0.
- Над заголовком воздуха минимум вдвое больше, чем под ним.

### 6.2 Ритм «как DJ-сет»
| Тип | Как выглядит |
|---|---|
| **DROP** | full-bleed видео или свет, минимум текста, максимум масштаба |
| **STATE** | одно гигантское утверждение + микроподпись, много черного воздуха |
| **LIST** | плотный набор имен/дат, типографика как фактура |

Два LIST подряд не ставить без DROP или STATE между ними.

### 6.3 Композиция
- Фон всегда черный; объект освещен (видео, лучи, градиент рассвета).
- Воздух — черное поле, а не серые плашки. Карточки только при реальной иерархии.
- Артист всегда стоит в теплом свете (градиент портрета, луч, блоб), никогда на ровном черном.

## 8. Моушн

### 8.1 Тезис (impeccable `animate`)
- **Focal moment:** «Восход» в hero. Черный экран → 16 лучей солнца вырастают из линии горизонта → лучи работают как маска, сквозь которую проступает портрет на рассветном фоне → маска раскрывается, hero-frame «приземляется» со скруглением снизу → слово SUNRISE въезжает гигантским кеглем (REF-4) и встает за/под портрет. До 2.4 с, один раз за визит.
- **Continuity:** солнце путешествует по странице: мини-иконка навбара, центр орбит в Play together, центр веера-дуги, маркер на таймлайне, финальный закат.
- **Feedback:** hover/focus на CTA, папках, строках тура и площадок.
- **Budget:** одновременно ≤ 1 видео со звуком и ≤ 2 muted-loop в зоне видимости; WebGL (Velvet Haze, Halftone) только в зоне видимости; всё на паузе вне экрана.

### 8.2 Токены
| Токен | Значение |
|---|---|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` |
| `--ease-light` | `cubic-bezier(0.33, 0, 0.2, 1)` |
| `--d-instant` | 120ms |
| `--d-fast` | 240ms |
| `--d-base` | 420ms |
| `--d-slow` | 720ms |
| `--d-hero` | 2400ms |
| `--stagger` | 40–60ms, сумма в группе ≤ 600ms |

Bounce/elastic не использовать. Выход быстрее входа.

### 8.3 Материалы
clip-path и mask (лучи, раскрытие видео, занавес), blur (вход крупных цифр), свет (`brightness`, прозрачность градиентов), масштаб от скролла, SplitText по строкам/буквам, FLIP (папки, фильтр площадок, веер).

### 8.4 Запреты
Одинаковая fade-up на каждой секции; `window.addEventListener('scroll')`, `scrollY` в state, rAF с setState; кастомный курсор; scroll-cue в hero; анимация `width/height/top/left/margin`; бесконечные микроанимации иконок.

### 8.5 Reduced motion (обязательно)
Hero сразу в финальном кадре; pin-сцены становятся статичными блоками; видео не автозапускаются (постер + Play); счетчики сразу показывают итог; орбиты и marquee стоят (статичный список); WebGL-фоны заменяются статичным `--g-sunrise`.
